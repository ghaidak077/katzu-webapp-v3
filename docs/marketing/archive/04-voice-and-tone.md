# 04 — Voice & tone (marketing Arabic)

Base: the product persona is a witty, deadpan cat that roasts German grammar — never the learner (PRODUCT-SPEC:91). Marketing inherits this; where the doc is silent, rules below decide.

## Register
- Clear MSA with light, natural warmth. Dialect touches ONLY where marked (posts may lean Levantine/Egyptian lightly since the launch market is Syria/Iraq-heavy; taglines flagged ⚠️ per doc 03 need a register check).
- Second person singular for the learner (أنتَ/أنتِ neutral forms), Sie-register NEVER discussed in marketing (that's lesson content).
- Short sentences. One idea per line. Numbers in Eastern Arabic numerals inside Arabic copy (٢٥٩) — consistent with existing app copy.

## When humor is allowed
- Social posts, video hooks, mistake-bank jokes about GERMAN grammar (der/die/das chaos, Perfekt particles), mascot moments.
- Example (allowed): «الألمانية بتختبر صبرك قبل لسانك: das Mädchen مؤنثة بس... 🔸» ⚠️

## When humor is BANNED (calm, plain, kind)
1. **Payment and checkout** (doc 13) — money + stress + scam fear. Zero jokes.
2. **Errors and failures** (support, doc 14) — the learner is already frustrated.
3. **Exam anxiety** — countdown messages, exam-day checklist, post-exam branches (doc 17). The cat is calm and warm here.
4. **Refunds and complaints.**
5. Anything about a person's accent, speed, or intelligence. The roast target is grammar, never the human. (Existing persona rule; restated because marketing breaks it easily.)

## Do / Don't
| Do | Don't |
|---|---|
| Name the fear, then the path: «قلق الامتحان طبيعي — هيدا بالضبط اللي بنتمرن عليه.» ⚠️ | Toxic positivity: «متقلقش، رح تنجح أكيد» |
| Specifics: «تصحيح من جملك انت» | Adjectives: «مذهل، ثوري، سحري» |
| Honest mechanics: «النتيجة محسوبة من كلامك المستقل» | Fake warmth: «أحبك يا طالبنا العزيز» |
| Cat as companion: «كاتزو معك» | Cat as judge: «القط راح يشهد عليك» |

## Banned claims (any file, any language)
1. Official / affiliated / recognized by Goethe, telc, ÖSD, DTZ, BAMF. (Always: «بأسلوب» / "in the style of".)
2. Guaranteed pass / "نجاح مضمون" / pass-rate percentages (none exist).
3. Fluency timelines («في ٣٠ يوم») — MARKETING-KIT §9 rule 1 restated.
4. "Replace your course / teacher".
5. Any statistic about learners, scores or outcomes until it exists (doc 16 rules).
6. Store-comparison attacks (ChatGPT/Duolingo named negatively in public copy).
7. "Free" for anything that isn't (free first mock = free; the pass is not).
8. Urgency except the learner's own exam date (no countdowns to fake deadlines, doc 17).

## Native-read protocol
Every Arabic block in files 07–09, 12–17 ships only after: (a) one native speaker reads aloud and flags anything that "sounds translated"; (b) register check against this file; (c) banned-claims scan. Track in doc 22.
