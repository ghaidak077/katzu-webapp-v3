# 18 — Habit design (exam pass → daily companion) — FUTURE, not launch

Position: launch sells the exam rehearsal. Daily habit is Stage 2+ (post-pass, doc 03). Every item below waits for a metric trigger (§priority) — building habit features before retention data exists is the classic launch killer (theory of constraints).

## The Fogg fit (why this can work)
- Motivation: post-pass, motivation shifts to «ما فقدت اللي بنيت» (loss aversion) + work/social German needs.
- Ability: 2-minute mission — smaller than any existing session type (shipped sessions are 5–10 min; a 2-min version is new, FUTURE).
- Prompt: daily mission notification at the user's chosen time; NOT streak-guilt.

## Items (priority order; each tied to a metric; none promised publicly until shipped)
1. **المهمة اليومية المصغّرة (2-min mission)** — one scene, one correction, done. Trigger to build: D7 ≥ 25% and daily-mission opt-ins plateau. Metric: D30 ≥ 12%.
2. **عداد الجاهزية (readiness %)** — exam-focused composite (mock trend + review mastery + recent activity). Exists partially (progress); FUTURE: make it the home screen anchor for exam-dated users. Metric: mock frequency ↑ without D7 drop.
3. **بنك الأخطاء كطقس (mistake-bank ritual)** — daily 3-card review of returned mistakes (SRS already ships the engine); framed as «تصفية أخطائك» not homework. Metric: review completion ≥60% of days active.
4. **لوحة الكوهورت (cohort board)** — teacher cohorts see collective improvement % (their teacher's badge visible). Improvement-ranked, never absolute-score-ranked (fairness, doc 16). Metric: cohort mock completion vs solo users ≥+20%.
5. **«ضاعف وضعك الحقيقي» (bring your real situation) mode** — paste the letter/email you received (Bürgeramt, employer), rehearse that exact conversation with the AI. THE daily-companion unlock: Katzu becomes the place you rehearse real life, not just exams. Needs engineering (new input path + safety rules for personal data — GDPR review first, FOR VERIFICATION). Trigger: D30 ≥12% sustained + user interviews asking for it.
6. **Post-pass identity arc** — «خريج B1» badge + B2 track + career scenarios as the natural next goal (goal gradient restart). Trigger: ≥30 users pass the exam (doc 16 pipeline knows).

## Hook-model fit (ethical application)
Trigger (notification chosen by user) → action (2-min mission) → variable reward (new debrief insight; the cat's take; readiness tick) → investment (mistake bank grows, readiness climbs — stored value that makes tomorrow's return more likely). The investment phase is honest here: the value accrues to the LEARNER's skill, not a lock-in wall.

## Ethical guardrails (hard)
- No guilt streaks, no loss-framed pushes («خسرت سلسلتك» banned — restated from doc 15).
- Notification frequency: user-chosen; ≤1/day; quiet hours respected.
- Readiness % always labeled «تقديري — ليس ضمان» (map≠territory).
- The 2-min mission can never be a paywall: habit features ride the pass (which already includes them) — no new paywall tier for the habit layer.
- Cobra-effect check each quarter: any incentive (badges, boards) that makes learners fake activity gets removed. Board participation is opt-in by default.
