# 09 — Video system (TikTok / Reels / Shorts; owner on camera, Arabic)

Metric that matters: **qualified mock starts** (link clicks → free mock started), not views. Vanity metrics are banned from decisions (doc 19 dictionary).

## Content pillars (rotate)
1. **Fear → rehearsal** (exam anxiety, named and solved) — 40%
2. **One honest correction** (real grammar fix, cat-deadpan) — 30%
3. **Proof/mechanics** (how scoring works, why no affiliation claims) — 15%
4. **Founder trust** (why I built this, payment honesty, no-card options) — 15%

## Cadence (sustainable solo rhythm)
2–3 videos/week = one 2-hour batch session weekly (Sunday): film 3–4 clips, caption, schedule. Never daily — the burnout kills the channel faster than the algorithm.

## The 12 scripts (20–30s each; hook ≤3s; on-screen text in Arabic; all ⚠️ native read)
**V1 — «السؤال اللي بيوقع أغلب الناس»** (pillar 1)
Hook: «٧ من ١٠ بيجيبوا هالسؤال غلط بالشفوي» [ASSUMPTION — replace with «أغلب الطلاب» unless a real number exists; NEVER invent statistics]
Demo: original part-2 question on screen («حدث عن يوم غيّرت رأيك في شيء») → owner speaks it → Katzu debrief appears → the one fix highlighted.
CTA: «المحاكاة الكاملة مجانية — الرابط بالبايو».
Alt hooks: (a) «امتحانك بعد شهر؟ هيدا آخر وقت للتدريب الصح» (b) «الأستاذ ما بيقدر يسمعك كل يوم. أنا بقدر.» (c) «الورقة بتنقذك، الشفوي بيوقعك.»

**V2 — «الغلط اللي بيتكرر»** (pillar 2)
Hook: «هيك جملة بيسمعها كل ممتح بيوم واحد عشرين مرة».
Demo: «Ich habe gegangen» → ❌ → «Ich bin gegangen» → the rule in one Arabic line → «كاتزو بيحفظلك هيذا الغلط ويرجّعلك ياه».
CTA: «جرّب وخلّي القط يصححلك».
Alt hooks: (a) «خطأ واحد بيتكرر... والتصحيح بيرجعلك تلقائياً» (b) «ChatGPT بيقولك gut gemacht. أنا بيقلك وين غلطت.» (only if doc 02 test passed) (c) «المفارقة: الكلمة الصح بسيطة.»

**V3 — «شو بصير بالتصحيح؟»** (pillar 3, screen-record heavy)
Hook: «شو الفرق بين تطبيق بيحلّلك وتطبيق بيصححلك؟»
Demo: full 25s screen recording: question → speaking → honest Arabic debrief → mistake card saved to review.
CTA: «بدون حساب، بدون فيزا — الرابط بالبايو».
Alt hooks: (a) «شوف شو بيصير بعد ما تلتس» (b) «النتيجة محسوبة من جملك انت — مش من المحاولات اللي ساعدك فيها التطبيق» (c) «صدق، بس بالعربي.»

**V4 — «٢٥٩ يورو»** (pillar 1, anchoring)
Hook: «الامتحان بـ٢٥٩ يورو. المحاكاة مجاناً.»
Demo: split screen — exam letter (recreated, no real document) vs the free mock running.
CTA: «جرب قبل ما تدفع».

**V5 — «بدون فيزا»** (pillar 4, trust)
Hook: «معكش فيزا؟ مش مشكلة.»
Demo: the manual-transfer → WhatsApp code flow in 15s (doc 13 copy as on-screen text).
CTA: «كل الطرق موصوفة على الموقع».

**V6 — «قصة قط»** (pillar 4, founder)
Hook: «ليش القط؟ لأن التعلم ما لازم يكون ممل.»
Demo: mascot + brand line «تتحدث. تخطئ. تتذكر.» + 3 app beats.
CTA: soft — «تعرف عليه بالرابط».

**V7 — «التخطيط المشترك»** (pillar 1) part-3 rehearsal: «أنتم تخططوا رحلة» — two founders? No: owner plays both sides via the app's partner mode; CTA as V1. Alt hooks: (a) «الجزء الثالث: ما تنتظر صديقك يحكي» (b) «خطة بـ٤ جمل = نقاط كاملة» (c) «الشريك اللي ما بيحرجك».

**V8 — «التقدّم الحقيقي»** (pillar 3): readiness % and before/after score card (only after real data exists — placeholder edit until then; do NOT publish this one before doc 16 produces the first honest card).

**V9 — «خدعة الشد الحرفي»** (pillar 2): «بالألمانية الشد الحرفي بيتحرك» — zug/durch/über with motion verbs; one original example; CTA as V2.

**V10 — «قلق الامتحان»** (pillar 1, calm tone — humor banned): «طبيعي تخاف. تدريبك بيبني ثقتك — محاكاة بمحاكاة.» breathing-room pacing; CTA soft.

**V11 — «مين ورايك؟»** (pillar 4): teacher partner says ONE sentence on camera (only with a Lead Partner who consented; script: «راجعت المحتوى بنفسي — هيدا التدريب اللي بنصح فيه طلابي.») — the authority asset; hold until a real partner exists.

**V12 — «ما بتنجح؟ ما بتنخدع»** (pillar 3, honesty flex): «ما بنوعدك بالنجاح. بنعطيك مستواك الحقيقي — والقرار قرارك.» ends on the free mock. This is the trust anchor of the whole account.

## Filming checklist
Phone 1080p+ vertical, window light facing you; lavalier or quiet room; 3 takes max per hook (perfectionism = batch death); captions burned-in (most watch muted); app screen recordings 1080×2400 with the Arabic UI; no real learner data on screen.

## Caption + hashtag template ⚠️
{hook line} + {one-line value} + «الرابط بالبايو» + 3–5 tags: #تعلم_الالمانية #الالمانيا #امتحان_B1 #B1 #Deutschlernen — check current tag volumes monthly; drop dead tags.

## Batch schedule (Sunday, 2h)
0:00–0:20 review last week's qualified-mock numbers → pick this week's 3 pillars; 0:20–1:10 film; 1:10–1:40 screen-record app beats; 1:40–2:00 captions + schedule. Metrics review is IN the session so numbers shape content.

## Kill criteria
- 8 videos published, <1 qualified mock start per video average → hooks are wrong: rewrite top 3, run one week, then pause the channel 30 days and double down on teachers/groups.
- Any video class gets comments alleging affiliation → pin the non-affiliation reply (doc 03 wording) within the hour.
