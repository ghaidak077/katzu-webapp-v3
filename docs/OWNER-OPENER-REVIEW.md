# Owner review — the 227 Arabic first messages added in V47

Read this the way a learner would: the left column is what the partner says first, the
right column is the Arabic that appears behind the first bubble.

- **Source of truth: the worker's `/scenarios`**, not the authored 61-scenario catalogue.
  The two sets differ (49 scenarios are live); the catalogue is only the source for the next
  content refresh. `scripts/audit-opener-coverage.mjs` now fails the CI gate when *any*
  served first message has no Arabic, so this cannot silently break again.
- **What is listed:** the 227 glosses added by V47 in
  `scripts/language-data/opener-ar-extra.json` — 223 served by the worker, 3 B1 mock-exam
  part openers, and 1 code fallback. Two German lines are served by two scenarios each;
  the second id is shown in brackets.
- **Order:** A0 → A1 → A2 → B1 → B2, then the worker's own scenario order.
- **Verdict:** 209 rows read natural. **18 are flagged** below (3 `meaning`, 2 `unnatural`,
  9 `literal`, 4 `style`). Rows **154, 192 and 219** change the meaning and should be fixed
  first; the rest are phrasing preferences, not blockers.

**To fix one:** edit its value in `scripts/language-data/opener-ar-extra.json`, run
`node scripts/build-language-data.mjs --offline`, then `npm run verify -- --ci`.
Reply with corrections or «fine» and the marks are cleared.
