# 08 — Community plan (Telegram / WhatsApp / Facebook groups)

Rule zero: groups are earned, not spammed. One value post per group per week max; admin permission BEFORE anything. Every Arabic block ⚠️ native read. Never post codes in groups (05 abuse rules). All exam-style questions are ORIGINAL — never copied from released model tests.

## The 4-week speaking challenge
- **Rules:** signup via a personal DM to the owner (never public codes); complete ≥10 mocks in 30 days (in-app tracked); weekly check-in post per participant in-thread (their score progression — voluntary sharing).
- **Prizes (real, small, no cobra effect):** top 3 by *improvement* (not absolute score — fairness across levels): 3-month pass free. Everyone finishing ≥10 mocks: their before/after score card (doc 16 template).
- **Honesty guard:** scores are mock scores, explicitly «نتيجة المحاكاة ≠ نتيجة الامتحان الحقيقي» — map≠territory stated in the challenge rules.
