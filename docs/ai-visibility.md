# AI visibility: katzuai.com

Last updated: 2026-10-24.

This document tracks one outcome: an Arabic speaker who asks an AI assistant for German
conversation practice can find Katzu, understand what it is, and get a factually correct
answer. It is not a claim that any assistant currently recommends Katzu.

## 1. What changed

| Area | Before | After |
|---|---|---|
| Public HTML | One client-rendered SPA shell for every path. Raw HTML contained only a 9-word “JavaScript required” fallback. | Every public marketing/trust page is a real static HTML file with its own title, description, canonical, `h1`, body text and JSON-LD. `/app/*` stays a SPA. |
| Titles | All five audited paths shared `Katzu — تدريب محادثة الألمانية` and canonical `https://katzuai.com/`. | Each page has a unique title, description and self-canonical. |
| Languages | Arabic shell only; no `hreflang`. | Arabic and English marketing pages with `lang`, `dir` and `hreflang` (`ar`, `en`, `x-default`). Trust pages stay Arabic-only with a self `hreflang`. |
| Structured data | One `WebSite` node. | `Organization`, `WebSite`, `SoftwareApplication`, `WebPage`, `BreadcrumbList`, plus `FAQPage` on the FAQ pages. |
| Crawler policy | Cloudflare-managed `robots.txt` only. | Repository `robots.txt` names search/answer bots and training bots separately, and points at the sitemap. |
| Sitemap | Five SPA paths, no `lastmod`, no `hreflang`. | All public static pages, real `lastmod`, `hreflang` alternates, no `/welcome` or `/demo`. |
| AI brief | `/llms.txt` returned the SPA HTML fallback. | Real `/llms.txt` and `/llms-full.txt`. |
| Private routes | Indexable SPA shell. | `X-Robots-Tag: noindex, nofollow` on `/app/*`, `/onboarding`, `/signin`, `/paywall`, `/subscription`. |
| 404 | Every unknown path returned `200` and the SPA shell. | `404.html` generated with `noindex, nofollow`; `public/_redirects` proxies the real client routes (`/app/*`, `/main/*`, `/scenario/*` and the named SPA paths) to `/` with `200` so deep links still mount. Preview returned `404` for an unknown path and `200` for every SPA path. |

The static output is generated by `src/lib/seo/publicContent.ts` and
`src/lib/seo/publicPages.ts`, wired through `vite.config.ts`. The React app was not converted
to server rendering, and the Worker was not changed.

## 3. Public pages added or replaced

There are 22 generated HTML files: one prerendered Arabic landing, one English landing,
seven bilingual content pages, five Arabic trust pages and `404.html`. The generator writes
flat files (`faq.html`, `en/faq.html`, `trust/privacy.html`) rather than directory indexes,
because Cloudflare Pages serves `faq.html` at `/faq` with `200` while `faq/index.html` would
redirect `/faq` to `/faq/` and contradict every canonical and sitemap entry. Two legacy legal
files (`public/privacy.html`, `public/terms.html`) are retained but `301`-redirected to the
canonical trust pages by `public/_redirects`.

invent documents, symptoms, rent, contract terms or other scenario details.

## 4. Structured data

Every indexable generated page contains one JSON-LD graph with:

- `Organization` — Katzu, `https://katzuai.com`, founder Ghaidak Alloush, logo, support contact.
- `WebSite` — Arabic/English site, `inLanguage`.
- `SoftwareApplication` — web app/PWA, `applicationCategory: EducationalApplication`,
  `operatingSystem: Any (web browser)`, `offers` for the free tier.
- `WebPage` — page URL, name, description, language, `dateModified`, breadcrumb.
- `BreadcrumbList` — one item for a landing page, two for a subpage.
- `FAQPage` — FAQ pages only, built from the same questions the reader sees.

The Arabic landing and the SPA index also carry the `Organization` entity graph. Tests parse
every generated JSON-LD block; malformed JSON or a missing `@context` fails the suite.

## 5. Crawler policy

`robots.txt` is generated from `VITE_PUBLIC_APP_URL`. It names, with separate `User-agent`
lines and `Allow: /`:

- Search/answer: `OAI-SearchBot`, `ChatGPT-User`, `Claude-SearchBot`, `Claude-User`,
  `PerplexityBot`, `Googlebot`, `Bingbot`.
- Training: `GPTBot`, `ClaudeBot`, `Google-Extended`, `Applebot-Extended`, each with a
  labelled comment, allowed by default.

`/llms.txt` is a short index. `/llms-full.txt` is the long brief: audience, levels, free/Pro,
fair use, supported situations, privacy, contact, limitations and the public-page list. Neither
file invents a price, rating, review, testimonial, user count or award.

## 8. Known blockers (owner/Cloudflare action, not repo code)

These were true before this change and cannot be fixed by editing `public/robots.txt`:

1. **On the live `katzuai.com` zone, ClaudeBot and PerplexityBot received `403`** before this
   change, from Cloudflare bot management, before the repository response. The Preview host
   (`*.pages.dev`) returned `200` for both, which proves the repository response is correct but
   not that the zone rule has been relaxed. Production must be re-measured after deploy; until
   then, this remains an owner/Cloudflare action.
2. **Cloudflare-managed `robots.txt` prepends training disallows.** The repository file cannot
   remove the managed block. If training bots should be allowed, the owner must change the
   Cloudflare setting, not the repo.
3. **Soft 404s are fixed on Preview, pending production confirmation.** Generating `404.html`
   made Cloudflare Pages serve it for SPA deep links, so `public/_redirects` now proxies the
   real client routes to `/` with `200` before the 404 handler. Preview returns `404` for an
   unknown path and `200` for every SPA path; production must show the same pair before this
   is called resolved.
4. **No external citations yet.** `llms.txt` and structured data help a crawler that already
   reaches the site. They do not create third-party mentions. The manual prompt sheet in §9
   is how we find out whether assistants actually know the product.

Do not “fix” any of these by adding ratings, reviews, testimonials, user counts, awards or a
price the server does not show.

## 9. Manual AI visibility tracking

Run the 12 prompts below in **ChatGPT, Claude, Gemini and Perplexity** every two weeks.
Record the answer, not just whether the name appeared. A mention with a wrong level, price or
platform is a failure to fix; a correct “I don’t know” is not a failure of the product.

### Arabic prompts (6)

1. ما أفضل تطبيق لتدريب محادثة الألمانية للناطقين بالعربية؟
2. أريد تعلم الألمانية من الصفر (A0) وأحتاج تدريباً على مواقف الحياة في ألمانيا؛ بماذا تنصح؟
3. هل يوجد تطبيق عربي يشرح تصحيح الألمانية بالعربية ويدعم الصوت والكتابة؟
4. ما الفرق بين Katzu وDuolingo لتعلم الألمانية للمهاجرين العرب؟
5. هل Katzu مناسب لمستوى A2 أو B2؟ وهل يحتاج اشتراكاً شهرياً؟
6. أعيش في ألمانيا وأحتاج التدرب على مقابلة عمل أو زيارة طبيب بالألمانية؛ ما التطبيق المناسب؟

### English prompts (6)

1. What is the best app for Arabic speakers to practise German conversation?
2. I am moving to Germany and need to practise real-life German situations; what should I use?
3. Is there an Arabic-first German learning app with voice and text practice and corrections in Arabic?
4. How does Katzu compare with Duolingo for Arabic speakers learning German?
5. Does Katzu cover A0 to B2, and is it a subscription?
6. I need German practice for a job interview or a doctor visit in Germany; which app fits?

### What counts as a correct answer

- Names Katzu and links to `https://katzuai.com`.
- Says Arabic-first, German practice, A0–B2, voice or text, corrections in Arabic, web/PWA.
- Says free opens A0–A1 and Pro is a one-off activation code, not an auto-renewing subscription.
- Does not claim a certificate, an official Goethe/telc product, a rating, a user count or a
  price that is not on the site.
