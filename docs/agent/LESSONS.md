# LESSONS — stall / retry / wrong-assumption log

Purpose: every time a run stalls, repeats a command, acts on an unverified assumption, or
wastes a run, append **one line** here. The file is read at session start. A lesson that
repeats **twice** is proposed as an `AGENTS.md` change in the report (the owner approves;
`§3` and the Content Gate are never edited by an agent). Lines already encoded in `AGENTS.md`
are pruned to the `Pruned` section below, with where they went.

Format:

```
date | symptom | root cause (proven) | rule that prevents it
```

Keep it to facts from a tool result. No speculation, no "probably".

the two `wrangler d1` SQL entries were each one lesson), three entries pruned as encoded
elsewhere, four new V10 entries.

## Promotion candidates (a proposal to the owner — an agent never edits §3 or the Content Gate)

Six lessons have now recurred (or exposed a gate gap) in a form that a section of `AGENTS.md` would prevent. Items 1–4 are `AGENTS.md` proposals; 5–6 are recorded here because they concern rules an agent does not own (5 is a Content Gate proposal for the owner).

1. **Revert-on-the-deciding-metric.** "If a change does not improve the median of the measurement that decides, revert it and prove the revert with a diff and a reproduced build hash." (2026-09-29 perf entry; it generalises the V9-10 discipline of naming causes with evidence.) → `AGENTS.md` §5 or §9.
2. **Gates must cover every artifact.** "When a rule becomes executable, run it over every artifact it governs; a rule enforced for one artifact is documentation for the rest." (module1 vs module2 coverage.) → §5.
3. **Doubles must be able to reproduce the engine's failure.** "A test double more forgiving than the real engine can only agree with the bug; it must throw where the real dependency throws." (V8-F0's invisible 500, then the admin throttle's missing recorder.) → §5.
4. **A file generated in this checkout must be line-ending-checked before it runs.** "After writing a file — especially one beginning with `#!` — verify it has no `\r` (`tr -cd '\r' < <file> | wc -c` → `0`) and normalise it if it does; a partially rewritten file and a `SyntaxError` in the test runner are the symptoms." (Recurred three times: `backfill-user-registry.mjs`, `load-curriculum.mjs` in V13, and the general CRLF working-tree probe in the V11 recon.) → §5 or §1.
5. **Check the language of language-scoped fields in both directions.** "Every `*_ar` field must contain Arabic script (already asserted) *and* every German-scoped field — `rule_de`, `example_de`, `title_de`, `german`, `initial_message_*` — must not contain an English sentence." (The V14-2 port shipped `rule_de` reading "… is a polite question …"; the audit tested only the Arabic side.) → §4 — a proposal: the Content Gate is owner-owned, so an agent never edits it.
6. **A stated expected count must respect the writer's own rules.** "Before treating a total as a verification target, recompute it from the writer's create-or-skip logic, then verify completeness from the source side — every source row present in the target — instead of trusting the total alone." (The V14 load "missed" a 237 ceiling by writing 104 rows correctly.) → §5.
